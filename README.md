A backend REST API project developed using Spring Boot for managing books, members and book issue/return operations.

**Tech Stack:**

`Java` `Spring Boot` `Spring Data JPA` `Hibernate` `MySQL` `REST API` `Maven`

**Key Features:**

* 📖 Book Management
* 👤 Member Management
* 🔄 Book Issue & Return
* 🔍 Book Search
* 📄 Pagination & Sorting
